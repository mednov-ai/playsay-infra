# Lesson-safe host maintenance contract

The infrastructure control plane is an additional, disabled-by-default executing owner above the protected host policy. The original observer cannot grant installation or restart. A numeric infra release and the scoped control play own bootstrap, aggregate producers, policy and eventual enablement. Product images, API, schema and lesson records do not change.

AX41 is the sole persistent coordinator; AX41 and Selectel have local executors. Host roles have distinct directional HMAC keys, verified TLS to fixed IP/SNI destinations, body/path/time/nonce authentication and a persistent replay journal. Guest roles can publish only their own finite aggregate schema. No node receives another node's SSH, database, Kubernetes or metrics-read credential. Root-owned isolated Python entrypoints accept no arguments. The guest producer is unprivileged; sudo permits exactly the fixed no-argument read-only aggregate helper. Activity never contains identities, tokens, URLs, raw logs or lesson/session records.

Eligibility is [03:00,05:00) Europe/Moscow with synchronized clocks and an operation bound plus 120 seconds of margin. Installation has a 900-second planning bound; a restart has 120 seconds. A started dpkg transaction is not killed if it overruns. No subsequent critical stage starts beyond the window or near the next lesson opening. An overrun remains visible and may be reopened through read-only healthy recovery while retaining unfinished security debt. No automatic reboot or guest/QEMU restart exists.

A non-stealable cross-host lease and local executor lock serialize ownership. Native APT/dpkg locks remain authoritative. A complete snapshot contains PROD and DEV access windows with the application grace/extension semantics, unknown deadlines, next opening, LiveKit rooms/participants, collaboration/game/external connections, snapshot queue, direct guest TURN relays/controls/queued bytes, both nginx ingress surfaces and both independent Selectel TURN surfaces. Each observation bounds its entire direct read with read_started_at/observed_at, is healthy and at most 30 seconds old. Every second read starts at least ten seconds after the first read completed and retains the same workload/process generation. LiveKit/collaboration metrics are read directly from every ready process on fixed private ports, never from a cached monitoring query; process start identity participates in generation checks. Missing/unknown/malformed/future/stale/busy data denies work. Historical lesson rows are never cleaned to manufacture a zero.

Before observing a quiet interval, both cabinet ingresses reject new HTTP/WebSocket admission with 503 and Retry-After 60. Existing tunnels continue and remain activity across a graceful nginx reload. Login, monitoring and ACME remain accessible. AX41 blocks TURN control before DNAT and Selectel blocks native control input, including established controls used by cached credentials. Relay media ranges are preserved. Kernel relay sockets and control queues include TCP and UDP. TCP LISTEN Send-Q is queue capacity, not activity. Global nginx Reading/Writing includes every other active request; exactly the private status request is removed from Writing. Idle keep-alive Waiting is not an active request. Unrelated co-hosted active requests conservatively defer host maintenance too.

An uncommitted preparatory barrier expires after 60 seconds. A committed persistent hold on both hosts precedes a disruptive step grant and never expires automatically. The current source generations are persisted with the step. The fixed APT Pre-Invoke helper rechecks authority, native package database, audited batch, actual window, fences and generations while APT owns its frontend lock, before the first dpkg invocation. Further invocations may finish only that same entered transaction. Pre-install abort reopens promptly; uncertain transaction/partition/crash requires healthy reconciliation, never timeout takeover. Barrier restoration precedes nginx, native TURN and AX41 virtualization/NAT startup. Corrupt or orphaned state is a failure, never an empty lease.

Only a dependency-closed batch of reviewed package names, exact signed candidate hashes and known maintainer scripts/triggers may install. Reviewed source/key/config fingerprints prohibit a new source or authority from silently entering the batch. Removals, new dependencies, unsigned authority, unsupported hooks or protected-owner payloads defer. An additive policy-rc.d is installed only when absent or already exactly task-owned; operator policy is never replaced. The sealed native apt-pinvoke honors NEEDRESTART_SUSPEND for the transaction; list-only runtime inspection remains independent, and it cannot choose protected restarts. Ordinary systemd crash recovery is not masked.

Each owned service retains its first pending runtime-debt time through failed inspection, retries, package success, reload and reboot. Executable mapping/inode inspection proves obsolete runtime; clearing an existing debt also requires a changed process generation. Unsupported/inactive optional units are not started just to clear a warning. Guest VM/kernel and unreviewed package debt remain pending. Existing monitoring retains installation/reboot debt and adds service-specific 24h/72h age, source freshness, unknown runtime and stalled-lease/barrier signals. Alerting never overrides activity/time/admission guards. External notification delivery requires its own approved receiver acceptance.

Bootstrap and simulation are not executing acceptance. Installation stays disabled until role authentication, complete producer advancement, route exclusion, source health and scoped idempotence are proven. Actual eligible-window acceptance, runtime recovery and final release-head develop integration are recorded separately in the runbook/evidence.
