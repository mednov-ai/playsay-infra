# RF classroom collaboration route

The collaboration/Yjs route is independent from LiveKit signaling and TURN media. The api-gateway selector accepts only `off` or `rf-two-hop`; regional selection is valid only in production and only for exact Origin `https://online.honeyschool.ru`. Production desired state is `rf-two-hop`: fresh `.ru` responses use `wss://online.honeyschool.ru/collab/ws`, while `.school` stays direct. Dev remains `off`; production `off` is retained only as collaboration-specific rollback.

The explicit Selectel `/collab/ws` location precedes the generic proxy, preserves path and query, verifies the AX41 `online.honey.school` certificate over TLS 1.2, forwards WebSocket Upgrade, disables request/response buffering, and uses two-hour read/send timeouts. Access logging is disabled on both Selectel and AX41 exact collaboration locations because the query contains a short-lived token. Evidence must never contain URI/query, network addresses, headers, cookies, tokens, room/lesson/participant identifiers, or drawing content.

Deliver the explicit edge support before the active application configuration. Require a zero-active-lesson window, run the RF playbook in check mode, review the exact diff, apply once, then repeat check mode and require `changed=0`. Verify nginx configuration and service health, unchanged public listeners/UFW, both public WebSocket authorization boundaries, and the privacy validator. Then deliver application heartbeat, metrics, client replacement hygiene, and production `rf-two-hop`. No new listener, DNS record, certificate, VM, or firewall opening is part of this change.

Immediately after application delivery, prove `.ru` regional and `.school` direct token selection plus controlled half-open socket cleanup within 60 seconds. For the same UTC window, collect route selections, Yjs opens/closes/active count, heartbeat terminations, buffered bytes, backpressure, snapshot retries, service restarts, ingress health, and sanitized browser propagation count/p50/p95/max. Correlate LiveKit and media only by aggregate timestamps.

Acceptance remains one concurrent two-participant `.ru` lesson. Both browsers must run without VPN, drawing propagation p95 must be below 300 ms and every sample below one second, with zero unexpected collaboration reconnects, stale growth, drops, forced closes, snapshot retries, or service restarts. Multiple intentional tabs are allowed by the service but must be closed before the bounded canary count is evaluated.

On any breach, set only collaboration mode to `off` for fresh tokens, verify reconnecting clients select `.school`, and let existing RF collaboration sockets drain. Do not restart or reconfigure nginx, collaboration-service, LiveKit, coturn, identity, persistence, or classroom data as the first rollback action.
