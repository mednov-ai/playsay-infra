# Production release 01.004.13 evidence

Date: 2026-08-26

Production hotfix `release/01.004.13` promotes the lesson-access design accepted on dev at platform commit `9812e78400c2b8747537f7fe97e43bfffaaaef29`. The numeric platform branch HEAD is `b15c57a619dddd0e7172b7c9b7aea682f7d0e6f0`; the later commit changes only Jenkins finalizer memory. Reusable links remain valid for every invited lesson participant, admission is roster-aware, unknown visitors enter a teacher-controlled Lobby, teachers may kick/readmit, and an optional remembered browser session lasts 30 days. Entry uses one-time Keycloak assertions and never resets or replaces the user's password.

Jenkins release dispatcher 38 completed successfully with all 12 affected targets. Candidate commit `d7678a7ce818f75dc35fba54f58ee966d8c5ff25` reached `status: ready`, retained `release/01.004.12` as its base, recorded the accepted dev commit, matched the platform branch HEAD, rendered immutable digests, and set every production application to the fixed-width numeric branch.
