# Production release 01.004.01 evidence

Date: 2026-08-17

Production release `release/01.004.01` enables the existing `email-service` image with Mailjet in `playsay-prod`. The accepted platform commit is `fdc133188e98f6549d71a3a1d5b9bc711eee2cbb`; no platform source, image, digest, Liquibase or SQL change was introduced. Jenkins release dispatcher builds 11 and 12 produced ready infra candidates. The promoted fix candidate is `6086d0d43a3c8b8648dc04aef3bd97762be67214`.

The initial `release/01.004.00` sync created the service but its pod failed closed with `CreateContainerConfigError` because the Helm template referenced SMTP keys while `mailjet-api` was selected. No placeholder secrets were added. Fix release `01.004.01` renders credentials only for the selected provider and keeps those selected credential references mandatory. Default SMTP, dev Mailjet, prod Mailjet and explicit Unisender renders each contain only their own provider environment variables.

Before promotion, the application database contained all four email provider tables and nine applicable Liquibase changelog records. Custom-format backups were written under `/var/backups/playsay/release-01.004.00-20260817T201447Z`; SHA-256 verification and `pg_restore -l` passed for application, keyboard and Keycloak archives.

The production root and all 18 ArgoCD applications reached `Synced/Healthy` at the exact fix candidate revision. The `email-service` deployment reached `1/1` with a running pod, zero restarts, no SMTP environment variables and all seven expected Mailjet environment variables. The production primary API key has seven non-backup Event API callbacks (`sent`, `open`, `click`, `bounce`, `blocked`, `spam`, `unsub`), all `alive` at version 2. An authenticated unsupported-event smoke against `https://online.honey.school/api/webhooks/mailjet` returned HTTP 200 without exposing callback credentials.

Public smoke returned HTTP 200 for `online.honey.school`, `key.honey.school`, `online.honeyschool.ru` and `key.honeyschool.ru`; API health was `UP`, and discovery retained canonical issuer `https://ops.honey.school/keycloak/realms/playsay`.

Rollback changes the production ArgoCD root back to `release/01.003.00`. No database restore is required because the accepted release did not change the schema.
