# Release 01.006.07 chat and tools rail

## Reviewed scope

Platform source `bc94b8b89ecd885aac36edacabd05cbe86cbcd26` includes the running `01.006.06` classroom-scroll source `da6b90235f35b49ac450355f4882c12ac723d0a4`. Only API Gateway and web are affected image targets. Relative to `01.006.06`, the intended non-image production changes are enabling environment-local chat push and changing chat email cooldown from PT10M to PT30M; initial delay remains PT2M. Unaffected image/build metadata must remain unchanged.

The shared chat policy accepts teacher/student capabilities, including ADMIN+TEACHER, without granting a pure administrator access to private chat or widening the contact directory. Contacts include nullable username for normalized one-character prefix search. Independent contact/conversation retries preserve successful data. Desktop tools are top-aligned; mobile docking is retained, and the initial dice affordance differs from the last rolled face. Changed labels cover ru/en/de/fr.

Email eligibility is persisted with the message transaction, not conditioned on socket presence. Dispatch checks read markers, serializes per recipient, uses stable idempotency keys and bounded retries, freezes an attempted batch, and defers fresh batches behind its retry. No migration or historical eligibility backfill is included.
