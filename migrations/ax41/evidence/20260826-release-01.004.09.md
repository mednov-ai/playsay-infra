# Production release 01.004.09 evidence

Date: 2026-08-26

Production hotfix `release/01.004.09` promotes platform commit `e2f82907333809ed2e59daa3bef502237fe8c72c`, with the same fix merged into `develop` as `6af3f4a60e8a49e94f8f74cb24bbebf8d20d7bbd`. When WhatsApp or Safari reuses an already open `/join` document, the frontend now observes the replacement URL fragment, cancels the stale invite attempt and validates the newly opened code without requiring a manual page reload.

The focused invite-token suite passed four cases, including same-document replacement, and the production frontend build completed locally. Develop web build `web-dev-252` passed generate, lint, test, build, image publication, rollout and UI smoke.
