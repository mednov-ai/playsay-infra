## Rollout

Production was promoted manually in the declared order: root/data, backends, API, then frontends. The first backend pass exposed two fail-closed configuration omissions before API/frontend promotion:

- YAML 1.1 parsed unquoted `gameRealtimeMode: off` as boolean false. Infra release commit `ecbf93c` quotes the value and the collaboration replacement pod became healthy with zero restarts while the previous ready replica continued serving traffic.
- the first `game-adapter-service` deployment required the documented `playsay-game-adapter` token secret. The secret was created directly in the modern production namespace without printing its value; the service and API consume the same secret.

No legacy VPS host, legacy Jenkins job or legacy branch was contacted or mutated.
