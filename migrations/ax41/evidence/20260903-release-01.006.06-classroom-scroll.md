# Release 01.006.06 classroom material scrolling

## Source and regression evidence

- Platform source: `da6b90235f35b49ac450355f4882c12ac723d0a4`, numeric release `release/01.006.06`, based on current production/dev `62e1a01c`.
- The isolated two-canvas Chromium fixture reproduced repeated backward assignments from the resize callback with the teacher idle (for example 36 → 12 px). The deterministic regression failed at 100 px instead of 150 px before the fix.
- The fix keeps subscriptions stable across viewport updates, protects an active local gesture through inertia, flushes its final position, resumes remote following after a boundary gesture, and cancels obsolete scroll work at presentation changes.
- Local verification: 51 focused tests passed across canvas, viewport ordering and Yjs runtime; frontend lint and TypeScript/Vite production build passed. Existing Vite large-chunk warning remains.
- Browser verification: desktop/mobile widths 1200/390, modeled delivery delays 0/300 ms, differing container heights, wheel/PageDown, focused image, synthetic concurrent gestures and active resize. No backward writes in the fixed ordinary-scroll runs; both participants converged within normalized rounding tolerance. Focused image reached 540 px on both participants.
- This fixture uses actual canvas rendering with modeled ordered delivery, not a production lesson or live Yjs socket. Physical touch/trackpad inertia, native scrollbar dragging and a fresh production two-person lesson remain unverified. The deterministic inertia regression continues scroll activity beyond the previous 500 ms intent window. Simulated latency is not evidence about a VPN route.
