# Production release 01.007.01: YouTube manual metadata recovery

The owner requested production delivery of the YouTube metadata recovery hotfix. The source is `d564d9031b03d2b4a768e7c238f85609faf85df9`, containing recovery change `a0f30b17cd64c0f532286c7c4843c75fc11ece8a` and a method extraction required by static analysis. It descends from accepted production/develop source `ff739cb8292f105d3109935956776a108d351c94`.

The change restores full-duration entry and English-language confirmation for teachers, preserves confirmation on save/reopen, invalidates it when the video source changes, and offers recovery from a metadata failure. Known automatic duration/language restrictions remain authoritative. Manual metadata is scoped to the current material/video and does not become global automatic metadata. Technical stream failures remain separate from recoverable missing metadata. The product contract is maintained in platform `docs/material-video-metadata.md` and workspace `spec.md`.
